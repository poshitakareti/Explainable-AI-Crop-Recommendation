# Advanced GUI – Explainable AI Crop Recommendation

## Overview
An interactive machine learning application that recommends suitable crops based on soil nutrient levels and environmental conditions.

## Features
- Automatic download of the crop recommendation dataset
- Random Forest classification model
- Model accuracy evaluation
- Top 3 crop recommendations with model scores
- Input analysis using feature importance
- Interactive Gradio web interface

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Gradio
- Joblib
- Google Colab

## Input Parameters
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

## How to Run
1. Open the notebook in Google Colab.
2. Run the installation cell.
3. Run the project code cell.
4. Wait for the dataset to download and the model to train.
5. Open the Gradio link to use the application.

## Disclaimer
Recommendations are based on the training dataset and are not a substitute for professional agricultural advice.
